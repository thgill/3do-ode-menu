THIS BROWSER CAN'T WRITE TO THE CARD

Open this page in Chrome or Edge (or Opera, Vivaldi) on a computer. Safari, Firefox and phone or tablet browsers don't let web pages save files into a folder you pick.

In Brave, it's switched off: open brave://flags/#file-system-access-api, set it to Enabled, restart Brave and open this page again.

1. CHOOSE THE CARD

Put your FZ-1 ODE's microSD card (or USB drive) in this computer and choose its top folder, the one with boot.iso in it. The browser will ask you to allow this page to view and save files there.

If the browser won't let you choose the whole card ("contains system files"), choose a folder on it instead, such as the one holding your games, and run it once for each such folder.

Nothing is changed until you press MAKE COVERS. The page only ever writes the menu's own files: covers (_cover.img inside a game's folder, _art/<game>.img beside a game file), folder indexes (_odemenu.idx) and, for a whole card, one line in _odemenu.opt.

4. GAMES WITH NO PICTURE

FIND looks through libretro's pictures for one filed under another name. PICTURE uses a picture from this computer (or drop one onto the game). WEB opens an image search in a new tab: save a picture you like, then use PICTURE. Each cover is written to the card straight away.

Box art and screenshots come from libretro's thumbnail collection (libretro-thumbnails/The_3DO_Company_-_3DO), the pictures RetroArch uses. They belong to the games' publishers: fine for your own card, please don't share them. Covers fit 88×122 (a US long box is 63×122) with each picture's own 256 colours, the format of the FZ-1 ODE menu.
